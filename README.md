# Резервное копирование котиков на Я.Диск

Курсовая работа по модулю «ООП и работа с API».

Программа берёт картинку кота с текстом с сайта [cataas.com](https://cataas.com)
и загружает её на Яндекс.Диск в папку `AIEPYAPI-160` (название группы).
Картинка загружается на диск по ссылке, на компьютер она не скачивается.
Информация о загруженном файле (имя и размер) сохраняется в `result.json`.

## Запуск

```
pip install -r requirements.txt
python main.py
```

Программа попросит ввести:
1. текст для картинки — он же будет названием файла на диске;
2. токен с [Полигона Я.Диска](https://yandex.ru/dev/disk/poligon/).

## Пример result.json

```json
[
    {
        "file_name": "Привет.jpeg",
        "size": 45678
    }
]
```
